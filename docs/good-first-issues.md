# Good first issues

Ideas that need no deep knowledge of the codebase. Open an issue first to say you are taking one.

1. **Add a supermarket plugin** (e.g. a store with an official API or open data). Follow
   [adding-a-supermarket.md](adding-a-supermarket.md); the contract tests tell you when you are done.
2. **Translate the app.** UI strings live in `app/src/i18n/`; add `en.ts` and a language switch.
3. **More sample foods** with nutrition from a public source (cite it; never invent values).
4. **Pack-size parsing:** add cases to the tests for formats you see in real stores.
5. **Docs:** verify [remote-access.md](remote-access.md) or [releasing.md](releasing.md) on your
   platform and fix what differs.
6. **Accessibility:** labels and contrast checks on app screens.
7. **Diets and allergens:** extend the allergen/diet keyword lists (with tests).
